## 🚀 Local Development

Just open `index.html` in any browser — no build tools required.

```bash
# or with Python's built-in server
python -m http.server 8000
# then visit http://localhost:8000
```

## 📦 Deploy to Vercel

1. Push this repo to GitHub
2. Import on [vercel.com/new](https://vercel.com/new)
3. Leave all settings as default (no build command needed)
4. Done — you'll get a public link like `studymate.vercel.app`
